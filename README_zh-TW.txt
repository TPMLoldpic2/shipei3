石牌車站 AR 明信片｜完整獨立版

1. 解壓縮，把此資料夾「裡面」的所有檔案與資料夾上傳到 GitHub 儲存庫的 Main（與 index.html 同一層），保留 assets、vendor 資料夾結構。
2. 在 GitHub Pages 設定選擇 main / root，等網站更新後，以手機開啟 HTTPS 網址並允許相機。
3. 按「開始掃描明信片」，對準包內 print_photo.jpg。可列印，或用另一台螢幕顯示；請保留整張照片、避免裁切及反光。
4. 辨識後火車與人物會循環活動。「調整模型」可暫停／繼續動畫、改變速度、大小、方向及高度；「結束掃描」會關閉相機。

此包已包含 index.html、程式、辨識檔、GLB、原照片和必要的前端函式庫，不需要再接舊版 INDEX。
這是獨立的石牌版本，介面沿用中華商場版本的樣式。

動畫模型：Shipai_Station_with_Train.glb
動畫名稱：Station_Life，48 秒循環。火車含完整機車及兩節車廂；人物含站門出口、站前行走、揮手與樹下坐著的老人。
模型是依照片製作的示意重建，未經歷史尺寸或車型考證。火車在基地內往返，並非連續從場景外進站。

更新既有 GitHub 網站時，請完整替換檔案；若仍看到舊畫面，可重新整理或清除網站快取。
手機相機權限與實際辨識穩定度需在手機上確認。
